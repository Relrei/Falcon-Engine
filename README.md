# Falcon Engine v0.7.1

これは半年前（2026年5月ごろ）に GTR（車）のシーンのレンダリングで40時間かかったことをきっかけに、レンダリングをどうにか速くできないかと個人的に開発を始めました。
本ビルドは今のところ Linux を優先して開発を進めており、順次 Windows にも対応する予定です。一部機能は NVIDIA 専用ですが、macOS も対応する予定はあるものの、当分先になると思います…。
もともと公開する予定はなかったのですが、DLSS RR が Blender に登場することをきっかけにオープンソースとして出すことを決めました。
（本当は売ってみたかったけど…なにせサポートしづらいのもあるし…自分は RTX 3080 を使っていて、このカスタムビルドは RTX 30 番台以降が性能を発揮しやすく、共有したかったからです。RTX 20 番台も技術面では対応していると思いますが、GTX は非対応で、Radeon もまだ非対応です）

## 簡単な説明

まず、このカスタムビルドはランチャーを通して起動できるようになっています。もちろんランチャーなしでも起動できますが、ランチャー自体にもいくつか機能を持たせており、連携することで快適に使えるのではないかと思い作りました。

## Falcon Engine の中に現在入っているもの

- DLSS RR デノイザーでレンダリングするための経路（ライセンスの都合で同梱できないため、別途ダウンロードする必要があります）
- demo 版から複数の機能を外していますが、今後改善して再実装する予定です（VSE など）
- Cycles をベースにフォトンマッピングを使えるようにした双方向パストレーシングの実装

前述の通り Linux で開発している都合上、どうしても Linux が優先になります。Windows・macOS も順次進めていく予定です（ストレージが足りずなかなか進められない状況です）。

## 今後の追加予定

今後追加予定の機能は以下の通りです。

- VSE
- 新しいレンダリングエンジンの複数追加
- GPU 計算によるシミュレーション
- 既存の構造の最適化
- スカルプト高速化
- 仮想ジオメトリによるクラスター

といった感じでまだまだありますが、大まかに確定している内容がこれらになります。
資金面の都合で開発が急に止まることなどもありますが、ご了承ください。

また、開発者が個人的に追加するアドオンなどもランチャー経由で入れられるようになる予定です。

- リアルカメラプレイ
- ランチャー経由によるレンダリング予約
- Godot エンジンへのデータ出力サポート（未定）

## 公式 Blender との関係・不具合の報告

このカスタムビルドは独自に路線を逸脱するというより、公式を追いながら自身の線路も進んでいくという形になります。互換性の問題が出る可能性がありますが、その場合は [Issues](../../issues) へ不具合の報告をお願いします。公式 Blender には送らないようにしてください。個人によるカスタムビルドであり、公式とは関係ありません。
また、いくつかのデータはライセンスの都合により各自でダウンロードしてフォルダに入れていただく必要があります。その際はよろしくお願いいたします。
