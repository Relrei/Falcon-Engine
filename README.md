# Falcon Engine v0.7.1

日本語 | [English](README.en.md)

これは半年前2026/5月ごろにGTR（車）のシーンのレンダリングで40時間かかったことをきっかけにレンダリングをどうにか早くできないかをきっかけに個人的に開発を始めました
本ビルドは今のところLinuxを優先して開発が進み順次Windows一部機能はNvidia専用でMACも対応をする予定ではありますが、当分先になると思います…
もともと公開はする予定はなかったのですがDLSSRRがBlenderに登場することをきっかけにオープンソースとして出すことを決めました
（本当は売ってみたかったけど…なにせサポートしづらいのもあるし…自分は3080を使っていてこのカスタムビルドは30番台以降が性能発揮しやすく、共有をしたかったからです（20番台も技術的面では対応していると思います、GTXは対応してません、またRadeonもまだ非対応です））

## 簡単な説明

先ずこのカスタムビルドはランチャーを通して起動できるようになっています、もちろんなくても起動はできますが、ランチャー自体にもいくつか機能を持たせています、連携することで快適に使えるんじゃないかと思い作りました

## Falcon Engineの中に現在入ってるもの

- DLSS RRデノイザーでレンダリングするための経路があること（ライセンスの都合で同梱できないので一度ダウンロードする必要があります）
- demoから複数の機能を外していますが、今後改善して再実装しようと思っています（VSE）
- もう一つはCyclesをベースにフォトンマッピングを使えるように双方向を実装しています

前述通りLinuxで開発している都合上どうしてもLinuxが優先になります、Windows、MACも順次進めていこうと思います（ストレージがなくてなかなか進められない）

## 今後の追加予定

また今後追加予定が

- VSE
- あたらしいレンダリングエンジンの複数追加
- GPU計算によるシミュレーション
- 既存の構造の最適化
- スカルプト高速化
- 仮想ジオメトリによるクラスター

と言った感じでまだまだありますが大雑把な面である程度確定している内容がこれらになります
資金面の都合で開発が急に止まるなどもありますがご了承ください。

また開発者個人的に追加するアドオンなどもランチャー経由で入れられるようになる予定です

- リアルカメラプレイ
- ランチャー経由による　レンダリング予約
- Godotエンジンへのデータ出力サポート（未定）

## 公式Blenderとの関係・不具合の報告

このカスタムビルドは独自に路線を逸脱するというよりかは公式を置いながら自身の線路も進んでいくという形になります、互換性問題が出たりする可能性があります、その場合は[Issues](../../issues)へ、不具合の報告をお願いします、公式Blenderには送らないようにしてください、カスタムビルドと公式は何も関わりがありません、個人でのカスタムビルドになりますので
またいくつかのデータはライセンスの都合によりダウンロードしてファイルに入れてもらう必要があります、その時はよろしくお願いいたします
